# Player Incentive & Revenue Analytics

A sanitized SQL portfolio project based on real analytical work with gaming, incentive, signup, redemption, and player-performance data.

## Business questions

- Which customers redeemed an incentive for the first time?
- How much Coin-In, Theo Win, and Net Win was associated with redeemers?
- How many distinct trips did customers generate?
- How should customers be segmented using observed gaming activity?
- How did newly created accounts perform after signup?
- How much Free Play was issued or used by segment and location?

## SQL techniques

- CTEs
- LEFT JOINs
- ROW_NUMBER()
- Aggregations
- Distinct-trip logic
- Deduplication
- CASE-based segmentation
- Date-window filtering
- Daily and customer-level summaries

## Technologies

SQL Server / T-SQL, analytical SQL, customer segmentation, incentive analytics, revenue analysis.
