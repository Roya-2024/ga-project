# Marketing Offer & Winner Automation

Sanitized portfolio version of a real operational workflow built with Python and Pandas.

## What this project demonstrates

- Reads recurring Excel/CSV marketing and winner files.
- Standardizes column names and validates required fields.
- Removes duplicate patron records using business rules.
- Assigns Free Play values and maps them to offer identifiers.
- Builds upload-ready files for a gaming marketing system.
- Produces location-specific Excel reports.
- Supports automated Outlook distribution to location recipients.
- Tracks skipped, failed, and successfully processed records.

## Why it matters

The workflow replaces repetitive manual file preparation with a repeatable, auditable process and adds data-quality checks before marketing offers are loaded or reports are distributed.

## Technologies

Python, Pandas, OpenPyXL, CSV/Excel automation, Outlook COM automation, data validation, deduplication, business-rule processing.

> This public version uses synthetic identifiers and generalized business rules. No proprietary company data, customer records, production offer IDs, credentials, or confidential files are included.
