# Executive Database Metrics Dashboard

A sanitized portfolio summary of a real Power BI / executive-reporting workflow used to monitor database and marketing performance.

## Dashboard coverage

- Active customer accounts
- Local vs. non-local account mix
- International-address accounts
- New-account trends by reporting period
- Offer and signup activity
- Customer-level activity metrics
- Campaign and database-marketing performance

## Supporting workflow

The reporting workflow combines SQL-derived analytical datasets with Power BI measures and recurring refresh/reporting processes. Related Python automation prepares clean CSV/Excel outputs for management reporting and operational follow-up.

## Technologies

Power BI, SQL Server / T-SQL, Python/Pandas, KPI reporting, database marketing analytics, customer analytics.

## Privacy

The public portfolio intentionally excludes production screenshots, real customer counts, customer identifiers, company-only metrics, and confidential report data. The repository documents the metric design and technical approach using fictional names and generalized examples only.
